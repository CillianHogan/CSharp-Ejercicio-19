Adivina el Número en C#

Este programa en C# es un juego donde el usuario debe adivinar un número aleatorio entre 1 y 100.

## Funcionalidades
- Genera un número aleatorio entre 1 y 100.  
- Permite hasta 10 intentos para adivinar el número.  
- Indica si el número ingresado es mayor o menor que el número secreto.  
- Manejo de errores para evitar entradas no válidas.  
- Muestra un mensaje de felicitación cuando el usuario acierta.
